The Approach

A systems fix, not a visual refresh

Benchmark

Studied established systems, then diverged

Used Microsoft Fluent and Google Material as reference points for structure and rigor, then built a distinct visual identity suited to the enterprise's own products and users.

Audit

Mapped legacy UI across the full portfolio

Catalogued inconsistent navigation models, visual density, and duplicated interaction patterns for the same core tasks, making the fragmentation visible and prioritizable.

Codify

Centralized usability and accessibility once

Codified into 42+ reusable patterns and 65+ components, built centrally so no product team had to rediscover or reinterpret usability and accessibility rules on its own.

Scale

Rolled out product-by-product on shared foundations

Applied the system across floor operations, cage and credit management, table management, kiosks, and patron-facing mobile apps, each transformed using the same reusable foundation rather than a bespoke redesign.
